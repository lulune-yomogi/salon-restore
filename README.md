# サーバーの復元

サーバーが壊れたとき・乗っ取られたときに、バックアップから丸ごと戻すための入口です。
このリポジトリにはパスワードや鍵は入っていません。復元の手順そのものは、暗号化されたバックアップの中に入っています。

## 用意するもの

- 新しい Ubuntu 26.04 のサーバー（同じ VPS を「OS の再インストール」すると IP が変わらず楽です）
- Google ドライブにある、戻したい日のバックアップ（`20261014-031701.tar.age` のような名前）
- バックアップの鍵（`AGE-SECRET-KEY-1` で始まる1行）

## 手順

1. Google ドライブで、戻したい日のバックアップを右クリック →「共有」→「リンクを知っている全員」にして、リンクをコピーします。
2. 新しいサーバーに root でログインして、次の1行を貼り付けます。

```bash
curl -fsSL https://raw.githubusercontent.com/<ユーザー名>/salon-restore/main/restore.sh -o restore.sh && sudo bash restore.sh
```

3. 聞かれた順に、共有リンク → バックアップの鍵 → `yes` を入力します。あとは自動で進みます（30分前後）。
4. 終わったら、Google ドライブの共有を「制限付き」に戻します。

最後に表示される「結果」に、動いていないものや IP が変わったときの DNS の変更が出ます。
